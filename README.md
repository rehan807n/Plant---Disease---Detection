## About the Project
Our project is about detecting plant diseases using leaf images. We use deep learning to predict plant diseases from images.

## Dataset Details
- **Dataset Name:** PlantVillage
- **Dataset Source:** [Kaggle PlantVillage Dataset](https://www.kaggle.com/datasets/emmarex/plantdisease)
- **Total Images:** Approximately 20,638
- **Total Classes:** 15
- **Image Size:** 224 × 224 pixels

## Model
We are using MobileNetV2 with TensorFlow and Keras.

## Results
- **Training Accuracy:** 89.71%
- **Validation Accuracy:** 90.87%
- **Training Epochs:** 5

These are our initial validation results, not independent test-set results.
